# Продуктовый план Eidos: Zero Layer - "SaaS + вау" (2026-11-06)

Анализ трёх направлений: UI/UX (все 10 экранов), игровые механики/лор/достижения,
ассеты/звук/рендеринг. Игра в разработке, APK работает.

# ВЕРДИКТ

Ядро уже SaaS-уровня: rogue-lite с настоящей боевой глубиной (намерения врагов,
Овердрайв, 10 синергий чипов с кодом в бою), PoE-крафт, онбординг с озвучкой ЕВА-09,
связный лор 8/10. Отстаёт "обёртка обещаний": half написанных вау-компонентов не
подключены, часть механик - декорация, эндгейм пуст, звук дешёвый.

Главная тема аудита: **многое уже написано, но не включено**. Значительная часть
вау-эффекта достигается подключением существующего кода.

# НАХОДКИ ПО СРЕЗАМ

## 1. UI/UX (агент)

- 3 параллельные палитры (Theme.kt x2 + неиспользуемый ZzzDesignSystem.kt),
  191 уникальный хардкод-цвет, 4 разных "золота" и 3 разных красных
- 3 системы кнопок: ZzzMainButton (правильная), Material Button, Card+clickable
- Hub/Inventory/Onboarding вообще не используют ZzzUiKit
- Написано, но НЕ подключено: CyberGlitchShader, CyberTiltModifier,
  CyberSkeletonLoader (CyberHUD.kt:538), TerminalTutorial, RelicShowcase
- Хаптики: Raid 34 вызова, Codex 0, Inventory 2, Shop 2
- 174 вхождения шрифтов 8-9sp; кнопка настроек ~24dp тач-таргет (гайд 48dp)
- Слабые экраны: Settings ("дебаг-панель" с admin-кнопками в основном списке),
  Forge (фейковый bottomBar: обе кнопки = onBack; 0 анимаций в кузнице),
  Pvp (бой без визуализации, результат мгновенно текстом), Codex (0 анимаций,
  свой MediaPlayer мимо EidosAudioManager), Inventory
- Пустые состояния есть только в Inventory; skeleton/error нигде
- Onboarding сильный (видео + 5 шагов + озвучка), нет общего skip, ник обязателен

## 2. Механики/лор/достижения (агент)

- Core loop 7.5/10, XP-кривая до 31 уровня, стрик-петля, 6 глав лора
- ДЫРЫ: World Boss = `remember { mutableStateOf(984124510L) }` в HubScreen.kt:168
  (сброс при перезапуске); Терминал Сингулярности (финал из 3 концовок) не
  существует - флаг hasSingularityTerminal никто не читает; 3 из 9 мутаторов
  (ANTIGRAVITY, GLITCH_STORM, ECHOES_PAST) показываются, но не реализованы;
  meta_key_level покупается и ничего не даёт; getAdvice() не вызывается из UI
  (30 советов мертвы); налог эвакуации 8% против лога "12%" против 0% в endRaid
- Экономика: после 5000м награды x3.5 при +25% сложности - фарму нечего
  сдерживать; осколки: доход 1-2/день против цен меты 50+
- Лор 8/10: сквозной сюжет с предвестиями; финал неинтерактивен, враги не
  привязаны к главам, радио 3 раза за жизнь, "Протокол Мужчины с Марса"
  выбивается из мира
- Достижения: 40 шт + трекер + 5 секретных работают; но геометрия кончается на
  200м (игра идёт до 10000м+), ноль ачивок за боевые системы (синергии, крафт,
  PvP, боссы)

## 3. Ассеты/звук/рендеринг (я)

- SFX: все 16 звуков синтезируются синусоидами в рантайме (EidosAudioManager,

  и 3 BGM
- Drawable: 262 файла / 174MB; ~49 без единой ссылки из кода; артефакты
  генераторов без ссылок: canva_ui_page_1-4 (9.2MB), canva_loot_card_template,
  bg_zzz_ui_kit_preview (2MB); ui_gemini_generated_imag.jpg (4.2MB, крупнейший)
  - 2 ссылки
- Иконки здоровы: 178 ZzzIcon, 62 ic_*, эмодзи в UI выкорчеваны
- VideoBackground реализован правильно (lifecycle, mute, fallback-градиент),
  но 10 экранов = 10 своих ExoPlayer (churn при навигации)
- Арт предметов: покрыто, кроме 6 событийных объектов (сундуки/портал/алтарь -
  закрывает ProceduralCyberArt)
- CodexScreen играет 4-й BGM своим MediaPlayer в обход аудио-менеджера
