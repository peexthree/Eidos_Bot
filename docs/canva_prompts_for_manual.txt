CANVA MAGIC MEDIA - 36 ПРОМПТОВ ДЛЯ ГЕНЕРАЦИИ
================================================================
Как генерировать (в твоём Chrome, аккаунт уже залогинен):
1. canva.com -> в поиске дизайн-типов набери "Magic Media" (или
   canva.com/ai-image-generator)
2. Вставь промпт из блока ниже -> Generate
3. Из 4 вариантов скачай лучший (кнопка Download / стрелка)
4. Сохрани файл в D:\EDO\canva_raw\ под ИМЕНЕМ, указанным в шапке блока
   (например monster_20.png). Расширение любое - я приведу сам.
5. Если вариант не понравился - Generate ещё раз (та же кнопка).

Советы: соотношение сторон выбирай Portrait (вертикаль) если спроит.
Все промпты на английском - так Magic Media работает лучше.
Можно генерить в любом порядке, какие нравятся.
