# UX-ПЛАН: упрощение и сращивание интерфейса (2026-11-07)

Диагноз: экраны по отдельности доведены, но живут ПОРОЗНЬ - игрок таскает контекст
руками (предмет из инвентаря → верстак = выйти, зайти, выбрать заново). Ниже - что
срастить, что упростить, в каком порядке.

## А. СРАЩИВАНИЯ (главные улучшения - убрать лишние переходы)

### A1. Инвентарь → Кузница (передача предмета) - ВЫСШИЙ ПРИОРИТЕТ
Сейчас: выбрать предмет → понять, что нужен верстак → выйти в Хаб → открыть
Кузницу → заново найти тот же предмет в списке.
Делаем: на карточке предмета в Инвентаре кнопка «🔧 К ВЕРСТАКУ» - Forge открывается
с этим предметом уже загруженным (передача itemId через MainViewModel).
Файлы: InventoryScreen, MainViewModel (forgeItemId StateFlow), ForgeScreen, MainActivity.

### A2. Магазин → «ЭКИПИРОВАТЬ СЕЙЧАС» из церемонии покупки
Церемония приобретения показывает картинку - добавить кнопку «НАДЕТЬ СРАЗУ»
(экипировка купленного предмета одной кнопкой, минуя инвентарь).
Файлы: ShopScreen (церемония уже есть), MainViewModel.

### A3. Лидерборд (Profile) → PvP-вызов
В глобальном рейтинге напротив оператора - кнопка «ВЫЗОВ» → PvpScreen с выбранной
целью. Рейтинг становится стартовой точкой PvP, а не просто таблицей.
Файлы: ProfileScreen, PvpScreen (принять цель извне), MainActivity.

### A4. Хаб → радио-индикатор
Непрочитанные радио-сообщения (Кассандра!) = бейдж на кнопке Профиль в Хабе.
Игрок узнаёт о новой серии сразу, а не при случайном заходе.
Файлы: HubScreen, MainViewModel (unread count).

### A5. Смерть → «Вернуться и забрать могилу»
Экран смерти: кнопка не только «в Хаб», но и прямая «К МОГИЛЕ» - могила создаётся
на глубине смерти; corpse run - самый частый мотив возврата, сократить путь.
Файлы: RaidScreen (DeathScreenOverlay), MainViewModel.

## Б. УПРОЩЕНИЯ (убрать лишнее с экранов)

### B1. Хаб: разделить «состояние» и «навигацию»
Хаб вырос: баннер World Boss + дейлики + реликвии + модули + ресурсы.
Порядок сверху вниз: 1) ресурсы (пили) 2) дейлики (что делать сегодня)
3) World Boss (соццель) 4) сетка модулей 5) реликвии → ПЕРЕНОС в Кодекс
(раздел «Артефакты», рядом с аудио-логами - тематически родное место).
Файлы: HubScreen, CodexScreen.

### B2. Рейд: панель действий по частоте
Атака - большая центральная; Защита/Способность/Расходники - ряд поменьше;
Бежать - маленькая в углу с подтверждением (критичное действие подальше отслучайных касаний).
Файлы: RaidScreen (RaidControls).

### B3. Единый заголовок экрана
Паттерн Settings (ZzzWindowCard-заголовок + стрелка назад) повторить на
Inventory/Shop/Forge/Codex/Pvp - один узнаваемый хедер на весь мир.
Файлы: 5 экранов.

### B4. Единый переход между экранами
CyberGlitchShader-вспышка при смене маршрута (подключён на Hub - вынести в
общий_nav-хелпер), чтобы весь мир ощущался одним материалом.
Файлы: MainActivity (navigation wrapper).
